# Four Baskets listening clips

Sixteen local MP3 clips, one for each picture and its two possible demonstratives. Each clip says the complete sentence listed in `manifest.json`.

Generated from the project’s own sentence text using the installed FFmpeg/libflite `slt` English voice, with `atempo=0.9` and a short final pause. No runtime speech service or installed browser voice is required. Browser speech synthesis remains a fallback if an audio file cannot play.
