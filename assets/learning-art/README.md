Learning picture replacement, November 2026

The old painted paper character/action set is replaced by original generated
workbook illustrations and existing object photos. actions.svg, people.svg and
extras.svg are self-contained SVG stacks. A fragment (for example
people.svg#glasses) displays just one complete, padded icon; the original raster
sheet is embedded once in each SVG. There is no runtime background-removal,
image mask or CSS crop applied to the character silhouettes.

manifest.json lists all 74 illustration fragments and the replaced PICS keys.
The original generation outputs remain in /workspace/generated_images.
The existing film clips, GIFs and detailed room scene activities are preserved.
