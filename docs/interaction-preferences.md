# Approved interaction references

The user selected these four references for future Spill the Word activities:

- **Rough Notation:** animated hand-drawn underlines, circles and highlights.
- **Page Flip:** turning pages in books and photo albums.
- **Typed.js:** typing, pauses, erasing and replacing text.
- **Lottie Interactivity:** animation controlled by hovering, pointer movement and clicks.

Use these when they serve the learning goal. This records the selection; it does not imply that all four libraries are installed.

Keep the cream background, Georgia serif type, wavy headings, existing illustrated marks and the agreed palette. Fridge words have no colored boxes; controls sit to the right and instructions expand inside How to. Kids, A1 and A2 use the beige fridge; B1, B2 and C1 use the blue fridge.
