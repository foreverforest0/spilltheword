# Find & say — Kids

Published in Grammar → Kids → Find & say. Direct activity URL:
`/#g=speak&tp=kids_search&lv=kids`.

Uses the three previously saved dense search illustrations unchanged, from
`/workspace/shared/downloads/wimmelbuch-preview`, and the existing 36 prompts and
teacher keys. No new illustration generation. Locations: department store, zoo,
amusement park. Topics include objects, colours, clothes, numbers, prepositions,
To be, There is/are, Have got and Present Continuous; one optional comparative.

Students locate details, tap the picture to leave a removable marker and answer
aloud. Marking is not automatic correctness feedback. Teachers check the oral
answer; their key is closed initially and resets closed on every new task.
Zoom 100–400% and two-axis scrolling reveal details without cropping the source.
One prompt is shown at a time; previous/next navigate all twelve in each scene.
Scene, task and image-relative markers persist under `spill-kids-search-v1`.

Validation: `python scripts/check-kids-search.py`. The `KIDS_SEARCH_ROOT` override
runs the same flow against the isolated production checkout before publication.
Covers catalog entry, all 36 prompts, zoom, markers, hidden keys, persistence,
320/390px screens, and direct links.
