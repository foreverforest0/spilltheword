# Ocean Sentence Expander

Replaces the old course-word / Easy–Medium–Hard expander with one guided five-change sequence for every numbered grammar topic: Kids (9), A1 (14), A2 (13), B1 (11), B2 (13), C1 (6). The existing home book opens its level/topic selector; each grammar topic also contains a Sentence Expander exercise.

`sentence-expander-data.js` holds reviewed starting sentences, short transformation cues, optional one-word starters, principle-only hints and accepted examples. All 330 cues across Kids–C1 were edited to remove ready-made target phrases and clause openings. Cues identify an edit, a semantic contrast or a small keyword set; the learner reconstructs the grammar. Its vocabulary substitutions keep names and objects consistent within a dive. The complete curriculum is exported in [sentence-expander-curriculum.md](sentence-expander-curriculum.md).

Write mode starts each edit with the previously accepted sentence. A successful check appends the next block and scrolls down; prior answers remain visible and read-only. Short cues still specify the changed detail and preserve the rest of the previous version. Full models are absent from unanswered cards, including when Hint is open. Write mode unlocks a comparison example only after a correct own answer; it stays optional. Local checking accepts the listed alternatives, contractions, punctuation and case variants. It is not a general-purpose semantic grader. Speak mode preserves oral practice and reveals a model after the learner confirms speaking.

The original Codrops BlockRevealers `RevealFx` and its bundled anime.js dependency are vendored locally with MIT notices. New blocks use the original cover–uncover effect. Reduced-motion mode reveals immediately. Existing ocean depth/scroll ideas are reused within this activity; the removed standalone Deep Sea game is not restored. Artwork reuses the site's paper fish.

Copy link retains the current task, completed edits, draft, hints and post-answer comparison state. The replay waits for disabled controls and busy reveals, then restores the current depth through `stw:shared-restored`. This also supports a teacher and pupil using different motion preferences. Existing live-answer snapshots include this activity's CSS and fields.

Run `python scripts/check-sentence-expander.py` with Python Playwright and Chromium. It checks all 66 actual catalog routes and complete dives, all 198 vocabulary variants / 990 model transformations, specific grammar rules, cue length, one-word starters, model-free prompts/hints, comparison gating before/after correct and incorrect answers, wrong/unchanged answers, real reveal animation, automatic descent, both directions of motion-preference sharing, oral practice, mobile layouts and cleanup on navigation. The ordinary sharing, live-answer transport and A1 practice scripts remain applicable.
