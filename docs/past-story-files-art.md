# Selected Story Files: artwork brief

Five selected original stories replace the earlier bag/presentation/power-cut drafts.
Source text, evidence, prompts, B1/B2 word lists and model stories are recorded in
`past-story-files-content.json`. These are fictional events, not retellings of episodes.

Each file has eight readable evidence cards. Reveal counts: 4,4,6,6,8,8,8.
The final two clues establish earlier events for Past Perfect, followed by a whole-story
prompt. Responses and reveals save separately for B1 and B2. No automatic grading.

Final artwork is pending. The draft uses factual document cards, not substitute images.
Use one visual style throughout. All text and dates are rendered separately as HTML.
